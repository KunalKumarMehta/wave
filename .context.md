## Project Overview
Wave is an AI-native browser assistant. Two deployment targets:
- Chrome Extension (MV3) — Side Panel with page awareness + agent actions
- Tauri Desktop App — Split-pane with embedded browser + chat sidebar
Both share `@wave/core` and `@wave/ui-components`.

## Architecture
- `packages/core/` — Platform-agnostic: adapters, agent loop, serializers, hooks, tabs, types
- `packages/ext-bindings/` — Chrome Extension: CDP, IPC, storage, tabs (chrome.tabs API)
- `packages/native-bindings/` — Tauri: CDP via WebSocket, DOM extractor, tabs
- `packages/ui-components/` — Shared React: chat, layout, generative, agent UI, tab bar
- `apps/extension/` — Chrome Extension (Vite + CRXJS)
- `apps/desktop/` — Tauri v2 (Vite + React + Rust, split-pane)

## Key Files
- `apps/extension/src/background.ts` — Service Worker (530 LOC)

## Build & Test
- `pnpm verify` — typecheck + test + build (all packages)
- `cd packages/core && npx vitest run` — 62 core tests
- `cd apps/desktop && npx vitest run` — integration tests
- `./scripts/bump-version.sh X.Y.Z` — version bump + git tag

## Conventions
- CSS: Vanilla CSS, BEM naming, design tokens in :root
- Imports: .js extensions (ESM). Dynamic import() for @mlc-ai/web-llm.
- API keys: Ephemeral only (chrome.storage.session / in-memory Map)
- Agent: Confirmation UI before actions. Vision fallback for sparse AX trees.
- Tabs: TabManager wraps platform TabController. Tools: open/switch/close/list_tabs.
- CI: GitHub Actions on push/PR. Release on tag push.
