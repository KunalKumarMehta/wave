# Wave — AI Context Rules
# Read this file to understand the project before making changes.

## Project Overview
Wave is an AI-native browser assistant built as a Chrome Extension (MV3).
It can chat with users, read web pages via CDP, and take actions on pages.
The codebase is a pnpm monorepo with platform-agnostic core logic.

## Architecture
- `packages/core/` — Platform-agnostic: adapters, serializers, state, types
- `packages/ext-bindings/` — Chrome Extension implementations of core interfaces
- `packages/ui-components/` — Shared React components (chat, layout, generative UI)
- `packages/native-bindings/` — Tauri bindings (stub, future)
- `apps/extension/` — Chrome Extension entry point (Vite + CRXJS)

## Key Files
- `apps/extension/src/background.ts` — Service Worker: routing, CDP, streaming
- `apps/extension/src/sidepanel.tsx` — Side Panel React app (multi-conversation)
- `packages/core/src/domain/adapters/` — OpenAI, Anthropic, Gemini streaming
- `packages/core/src/domain/ax-serializer.ts` — AX tree → Markdown+refs
- `packages/core/src/domain/context-builder.ts` — Token budget allocation
- `packages/core/src/domain/agent-tools.ts` — Agent tool defs + system prompt
- `packages/core/src/domain/conversation-storage.ts` — Conversation CRUD layer

## Conventions
- CSS: Vanilla CSS with BEM naming, design tokens in :root
- Files: kebab-case filenames, PascalCase component names
- Streaming: Use chrome.runtime.connect ports, NOT sendMessage
- State: Never store in service worker variables (use chrome.storage)
- Imports: Use .js extensions in import paths (ESM)
- Testing: Vitest in packages/core/tests/

## Known Issues
- AX tree tab-targeting may still return wrong tab from Side Panel context
- Gemini 2.5 Flash hallucinates on complex pages (model limitation)
- Markdown renderer: no nested lists, no task lists, no syntax highlighting
- Old flat `messages` key in chrome.storage.local may persist from pre-Sprint 10 — harmless but unused

## Build Commands
- `pnpm --filter @wave/extension build` — Build extension
- `pnpm test` — Run all tests
- Load `apps/extension/dist/` as unpacked extension in Chrome

## Critical Reminders
1. Always include page URL + title in agent context
2. Call setAccessLevel at SW top level for session storage access
3. Use lastFocusedWindow (not currentWindow) for tab queries from Side Panel
4. Normalize provider names to lowercase before adapter lookup
5. Detach chrome.debugger immediately after use to dismiss banner
