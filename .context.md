# Wave — AI Context Rules
# Read this file to understand the project before making changes.
# Last updated: 2026-05-13 (Sprint 15)

## Project Overview
Wave is an AI-native browser assistant with two deployment targets:
- Chrome Extension (MV3) — Side Panel chat with page awareness
- Tauri Desktop App — Native window with system tray + global shortcuts
Both share `@wave/core` and `@wave/ui-components`.

## Architecture
- `packages/core/` — Platform-agnostic: adapters, serializers, state, hooks, types
- `packages/core/src/hooks/` — Shared React hooks (useConversationManager, chat-utils)
- `packages/ext-bindings/` — Chrome Extension implementations of core interfaces
- `packages/native-bindings/` — Tauri implementations (IPC, storage, CDP via WebSocket)
- `packages/ui-components/` — Shared React components (chat, layout, generative UI)
- `apps/extension/` — Chrome Extension entry point (Vite + CRXJS)
- `apps/desktop/` — Tauri v2 desktop app (Vite + React + Rust)

## Key Files
- `apps/extension/src/background.ts` — Service Worker: routing, CDP, streaming (450 LOC)
- `apps/extension/src/sidepanel.tsx` — Side Panel React app (356 LOC)
- `apps/desktop/src/App.tsx` — Desktop React app (314 LOC)
- `apps/desktop/src-tauri/src/lib.rs` — Rust backend (69 LOC)
- `packages/core/src/hooks/useConversationManager.ts` — Shared hook (239 LOC)
- `packages/core/src/domain/agent-loop.ts` — Agent state machine (188 LOC)
- `packages/core/src/domain/ax-serializer.ts` — AX tree → Markdown+refs (197 LOC)
- `packages/core/src/domain/conversation-storage.ts` — Conversation CRUD (250 LOC)

## Conventions
- CSS: Vanilla CSS with BEM naming, design tokens in :root
- Files: kebab-case filenames, PascalCase component names
- Streaming: Extension uses chrome.runtime.connect ports; Desktop uses direct adapter.stream()
- State: Never store in service worker variables (use chrome.storage)
- Imports: Use .js extensions in import paths (ESM)
- Testing: Vitest in packages/core/tests/ (54 tests, 5 suites)
- Shared logic: Put in packages/core/src/hooks/ or packages/core/src/domain/

## Known Issues
- Desktop CDP needs external Chrome with --remote-debugging-port=9222
- Gemini 2.5 Flash hallucinates on complex pages (model limitation)
- Agent loop max 5 steps (may be too low for complex tasks)
- No action confirmation UI — agent executes without user approval
- Cost tracking metadata not consistently sent by all adapters

## Build Commands
- `pnpm --filter @wave/extension build` — Build extension
- `cd apps/desktop && pnpm tauri dev` — Tauri dev mode
- `cd packages/core && npx vitest run` — Core tests (54)
- Load `apps/extension/dist/` as unpacked extension in Chrome

5. Detach chrome.debugger immediately after use to dismiss banner
