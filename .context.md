# Wave — AI Context Rules
# Read this file to understand the project before making changes.
# Last updated: 2026-05-13 (Sprint 20)

## Project Overview
Wave is an AI-native browser assistant with two deployment targets:
- Chrome Extension (MV3) — Side Panel chat with page awareness
- Tauri Desktop App — Split-pane with embedded browser + chat sidebar
Both share `@wave/core` and `@wave/ui-components`.

## Architecture
- `packages/core/` — Platform-agnostic: adapters, agent loop, serializers, hooks, types
- `packages/core/src/hooks/` — Shared React hooks (useConversationManager, chat-utils)
- `packages/core/src/domain/local-router.ts` — WebLLM intent classification (replaces keywords)
- `packages/ext-bindings/` — Chrome Extension implementations
- `packages/native-bindings/` — Tauri: IPC, storage, CDP via WebSocket + DOM extractor
- `packages/ui-components/` — Shared React: chat, layout, generative, agent UI
- `apps/extension/` — Chrome Extension entry (Vite + CRXJS)
- `apps/desktop/` — Tauri v2 desktop (Vite + React + Rust, split-pane layout)

## Key Files
- `apps/extension/src/background.ts` — Service Worker: routing, CDP, streaming (490 LOC)
- `apps/extension/src/sidepanel.tsx` — Side Panel React app (400 LOC)
- `apps/desktop/src/App.tsx` — Desktop: split-pane + agent + local model (470 LOC)
- `apps/desktop/src-tauri/src/lib.rs` — Rust: tray, shortcuts, browser commands (120 LOC)
- `packages/core/src/domain/agent-loop.ts` — Agent state machine (220 LOC)
- `packages/core/src/domain/local-router.ts` — WebLLM intent router (93 LOC)
- `packages/native-bindings/src/dom-extractor.ts` — Webview JS injection (142 LOC)
- `packages/native-bindings/src/cdp.ts` — NativeBrowserController (198 LOC)

## Conventions
- CSS: Vanilla CSS with BEM naming, design tokens in :root
- Files: kebab-case filenames, PascalCase component names
- Streaming: Extension = chrome.runtime.connect ports; Desktop = direct adapter.stream()
- State: Never store in service worker variables (use chrome.storage)
- Imports: Use .js extensions in import paths (ESM)
- Testing: Vitest (62 tests, 6 suites)
- Intent routing: LocalRouter (WebLLM) with keyword fallback
- Agent actions: Confirmation UI before execution (desktop)

5. Detach chrome.debugger immediately after use to dismiss banner
